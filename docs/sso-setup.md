# الدخول عبر وزارة التربية والتعليم – دليل التفعيل

النظام جاهز للدخول الموحّد بمعيار **OpenID Connect** (تدفّق Authorization Code مع PKCE).
الميزة **معطّلة** إلى أن تُدخَل بيانات الربط التي تعطيها الوزارة في ملف `.env`.

## كيف يعمل
1. في صفحة الدخول زر "الدخول عبر وزارة التربية والتعليم".
2. يُنقل المستخدم إلى **صفحة الوزارة**، ويكتب فيها اسم المستخدم وكلمة المرور. **كلمة المرور لا تصل إلى نظامنا أبدًا.**
3. الوزارة تعيده مع رمز (code). نظامنا يستبدله بـ ID Token ويتحقّق منه بالكامل: التوقيع RS256 بمفاتيح الوزارة المنشورة، والمُصدِر، والجمهور (client_id)، والصلاحية الزمنية، والـ nonce الخاص بهذه المحاولة، و state ضد التزوير.
4. يُحسب من معرّف الشخص (مثلًا رقم الهوية) **بصمة مشفّرة** (HMAC-SHA256 بمفتاح سرّي)، ويُبحث عن الحساب المربوط بها. **رقم الهوية نفسه لا يُحفظ.**

## الربط – مرة واحدة لكل مستخدم
- لا تُنشأ حسابات تلقائيًا: حساب الوزارة يدخل فقط إلى الحساب الذي رُبط به.
- المستخدم يدخل بكلمة مرور النظام ← قائمة المستخدم ← "تغيير كلمة المرور" ← **"ربط حساب الوزارة"**، فيمرّ بصفحة الوزارة ويعود والحساب مربوط.
- يمكنه إلغاء الربط من نفس الصفحة. حساب وزارة واحد لا يمكن ربطه بحسابين.

## ما يُطلب من الوزارة
1. تسجيل النظام كـ "تطبيق" في نظام الهوية (OpenID Connect، تدفّق Authorization Code).
2. عنوان العودة (Redirect URI) – بالضبط: `https://<عنوان النظام>/auth/sso/callback` (HTTPS إلزامي).
3. بعد الموافقة تحصل على: عنوان المُصدِر (Issuer)، ومعرّف التطبيق (Client ID)، والسرّ (Client Secret)، واسم الـ claim الذي يعرّف الشخص.
4. هذا مرتبط بموافقة الوزارة على النظام وبتقييم الخصوصية (PIA) قبل التشغيل على بيانات حقيقية.

## الإعداد في `.env`
```
SSO_ENABLED=true
SSO_ISSUER=<عنوان المُصدِر من الوزارة>
SSO_CLIENT_ID=<معرّف التطبيق>
SSO_CLIENT_SECRET=<السرّ>
SSO_REDIRECT_URI=https://<عنوان النظام>/auth/sso/callback
SSO_SCOPES=openid
SSO_ID_CLAIM=<اسم الـ claim الذي يعرّف الشخص، sub إن لم يُذكر غيره>
SSO_HASH_KEY=<24 حرفًا عشوائيًا على الأقل>
```
- **`SSO_HASH_KEY`**: احفظ نسخة منه خارج الخادم مثل `BACKUP_KEY`. تغييره يلغي ربط كل الحسابات (يجب ربطها من جديد).
- `SSO_CLIENT_SECRET` سرّ: لا يُكتب في أي ملف آخر ولا يُرسَل بالبريد.
- يجب أن يعمل الخادم بـ HTTPS، وأن يستطيع الخروج إلى خوادم الوزارة (امتداد curl في PHP).

## الأمان
- دخول ناجح أو فاشل يُسجَّل في سجل التدقيق (`login` / `login_failed` مع `method: sso`).
- محاولة الدخول صالحة 10 دقائق، ولمرة واحدة.
- الدخول بكلمة مرور النظام يبقى كما هو، وكذلك قفل الحساب بعد محاولات فاشلة.
