# שיעור מקוון (LiveKit) – הפעלה ופרטיות

המורה פותח/ת מפגש חי מדף השיעור של היום, ותלמידי השיעור (הכיתה, או בקבוצת לימוד רק חבריה) נכנסים מהפורטל. הקול, הווידאו ושיתוף המסך עוברים דרך **שרת מדיה LiveKit** (קוד פתוח, Apache 2.0). DarsPlus עצמה אינה מעבירה מדיה: היא מחליטה מי נכנס ובאיזה תפקיד, חותמת לו אסימון גישה קצר־מועד (JWT, HS256), ומבקשת מהשרת לבצע את פעולות המורה (השתקה, הוצאה, נעילת מיקרופונים, אישור שיתוף מסך, סיום).

## מה יש במפגש

| | מורה (מנהל/ת המפגש) | תלמיד/ה |
|---|---|---|
| מיקרופון, מצלמה | ✓ | ✓ (אלא אם המורה נעל/ה את המיקרופונים) |
| שיתוף מסך | ✓ | רק אם המורה אישר/ה לו/לה |
| הרמת יד, צ'אט | ✓ | ✓ |
| השתקת משתתף / כולם, כיבוי מצלמה | ✓ | – |
| נעילת מיקרופונים של התלמידים | ✓ | – |
| אישור / ביטול שיתוף מסך לתלמיד/ה | ✓ | – |
| הוצאת משתתף, סיום לכולם | ✓ | – |

- **מי מנהל:** מי שרושם את השיעור – המורה של השיבוץ, או מי שרואה את כל בית הספר (הנהלה). איש צוות אחר שרואה את השיעור (רכז/ת) נכנס/ת בלי כלי ניהול.
- **הורים** רואים בפורטל שיש שיעור חי, אבל אינם נכנסים: הכניסה מחשבון התלמיד/ה.
- **מתי:** רק לשיעור של היום, שאינו מבוטל, בשנה שאינה נעולה. מפגש שלא נסגר נחשב סגור בסוף היום.
- **נוכחות:** נשמר רק מי נכנס ומתי (`online_meeting_participants`). בדף השיעור מסומן ליד כל תלמיד/ה "הצטרף/ה" או "לא הצטרף/ה", והכפתור "סימון מי שלא הצטרף כחסר" משנה רק את הטבלה – המורה בודק/ת ושומר/ת.
- **אין הקלטה**, והצ'אט אינו נשמר בשום מקום (הודעות עוברות בין הדפדפנים בלבד).
- **אכיפה בשרת:** הרשאות כל משתתף כתובות באסימון ובשרת המדיה; כפתור שהוסתר בדפדפן אינו ההגנה. תלמיד אינו יכול לשנות את שמו או את תפקידו (אין לו `canUpdateOwnMetadata`).

## סביבת פיתוח (Windows)

השרת הורד ל־`tools/livekit/livekit-server.exe` (גרסה 1.13.11; הקובץ אינו נשמר ב־git). מצב פיתוח, עם המפתחות הקבועים `devkey` / `secret`:

```bash
tools/livekit/livekit-server.exe --dev --bind 127.0.0.1
```

ב־`.env`:

```
LIVEKIT_ENABLED=true
LIVEKIT_URL=ws://localhost:7880
LIVEKIT_API_URL=http://127.0.0.1:7880
LIVEKIT_API_KEY=devkey
LIVEKIT_API_SECRET=secret
```

ספריית הדפדפן `livekit-client` 2.24.1 נמצאת ב־`public/assets/vendor/livekit/` (מוגשת מהשרת עצמו, כי ה־CSP מתיר רק `script-src 'self'`).

## ייצור

1. **שרת LiveKit** על שרת לינוקס (מומלץ Docker), לפי https://docs.livekit.io/home/self-hosting/deployment/ – או LiveKit Cloud. בשרת עצמי צריך לפתוח: TCP 443 (או 7880 מאחורי reverse proxy עם TLS), TCP 7881, ו־UDP 50000–60000 (או טווח שמוגדר).
2. **TURN** (מובנה ב־LiveKit, `turn.enabled: true` עם תעודה) – הכרחי לתלמידים מאחורי רשתות חסומות (רשתות בית ספר, סלולר).
3. **HTTPS חובה** גם ל־DarsPlus וגם ל־LiveKit (`wss://`): דפדפנים מאפשרים מצלמה ומיקרופון רק בהקשר מאובטח.
4. ב־`.env`: `LIVEKIT_URL=wss://live.<הדומיין>`, ומפתח וסוד חזקים מקובץ ההגדרות של השרת (`keys:`). הסוד נשמר כמו `BACKUP_KEY` – לא ב־git.
5. **קיבולת:** שיעור של 30 תלמידים עם מצלמות דורש בערך 2–4 ליבות ו־100 Mbit/s בשרת; LiveKit מתאים את האיכות לכל תלמיד (simulcast, adaptive stream).

## פרטיות – לפני שימוש עם תלמידים אמיתיים

- המדיה עוברת דרך שרת ה־LiveKit בלבד; שרת בבעלות הרשת/בית הספר בישראל עדיף על שירות ענן.
- יש להתאים לנוהלי משרד החינוך לשיעורים מקוונים (מצלמה אינה חובה לתלמיד, אין הקלטה בלי הסכמה, אין שיתוף קישורים מחוץ למערכת) ולתסקיר הפרטיות (PIA) של המערכת.
- הכניסה למפגש אפשרית רק למשתמש מחובר שהשרת אישר – אין קישור ציבורי, ושם החדר אקראי.
