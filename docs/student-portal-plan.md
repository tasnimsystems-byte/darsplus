# بوابة الطلاب والأهل

**الحالة: نُفّذت كل المراحل الخمس** (القرار D80 في `decisions.md`). ما يلي هو الخطة كما بُنيت.

- **المدير:** إدارة ← "حسابات الطلاب والأهل" ← اختيار صف ← إنشاء حسابات الطلاب / الأهل (قسائم أسماء المستخدمين وكلمات المرور تُعرض مرة واحدة للطباعة)؛ إصدار الشهادات ← "نشر الشهادات للطلاب والأهل".
- **الطالب / وليّ الأمر:** يدخل فيُنقل إلى "بوابتي": الرئيسية، علاماتي، حضوري، واجباتي، شهاداتي. وليّ الأمر يختار الابن/الابنة من قائمة في أعلى الصفحة.
- **الدخول عبر الوزارة:** كل حساب (طالب أو أهل) يستطيع ربط حساب الوزارة من صفحة الحساب، مثل المعلمين.

## ماذا يرى الطالب (قراءة فقط)
| الصفحة | المحتوى | من أين |
|---|---|---|
| الرئيسية | برنامج اليوم والأسبوع، آخر العلامات، تنبيهات | البرنامج الأسبوعي، التقييمات المنشورة |
| علاماتي | لكل موضوع: التقييمات المنشورة، المركّبات، العلامة الفصلية (مقرّبة للأعلى) | كشف العلامات (نفس الحساب) |
| حضوري | الغيابات والتأخرات لكل فصل، وملاحظات الدروس الإيجابية | تسجيل الحضور |
| واجباتي | الوظائف البيتية التي سجّلها المعلم في الحصة | توثيق الحصة (homework) |
| شهادتي | الشهادة بعد أن يقرّر المدير نشرها | إصدار الشهادات |

**لا يرى:** طلابًا آخرين، علامات زملائه، معدلات الصف، ملاحظات سلوك سلبية لم يقرّر المربي إظهارها، أي بيانات إدارية.

## الحسابات والصلاحيات
- دور جديد `student` بلا أي صلاحية على وحدات الطاقم؛ كل صفحات البوابة تحت `/me/...` ولا تقبل معرّف طالب في العنوان (الطالب يرى نفسه فقط).
- ربط المستخدم بسجلّ الطالب (`students.user_id`).
- إنشاء الحسابات: جماعيًا لصف أو طبقة (اسم مستخدم + كلمة مرور أولى تُطبع أو تُوزَّع)، أو الدخول عبر الوزارة فقط بعد الربط.
- قرار مطلوب: هل يرى الأهل البوابة أيضًا (حساب أهل منفصل لكل طالب)؟

## التصميم
- نظام التصميم جاهز: الثيم `teen` (الإعدادي والثانوي) و`junior` (الابتدائي) في `tokens.css`، مع الوضع الليلي.
- الهاتف أولًا: الطلاب يدخلون غالبًا من الهاتف.
- لغة الواجهة حسب المدرسة (عربي/عبري).

## الخصوصية والقانون (قبل التشغيل)
- تحديث تقييم الخصوصية (PIA) ليشمل وصول القاصرين إلى بياناتهم وتسجيل الدخول.
- موافقة الوزارة على وصول الطلاب، وسياسة استخدام مكتوبة للطلاب والأهل.
- سجل تدقيق لكل دخول طالب؛ لا تتبّع ولا تحليلات خارجية.
- نشر الشهادة للطالب بقرار صريح من المدير (لا تلقائيًا).

## مراحل مقترحة
1. **الأساس:** دور الطالب، ربط الحساب بسجلّ الطالب، إنشاء حسابات جماعي، صفحة رئيسية بالبرنامج.
2. **علاماتي وحضوري:** قراءة فقط من البيانات الموجودة.
3. **واجباتي وشهادتي:** مع زر "نشر الشهادات للطلاب" في صفحة المدير.
4. **الدخول عبر الوزارة للطلاب:** بعد موافقة الوزارة، بنفس المكوّن الموجود.
5. (اختياري) بوابة الأهل.

كل مرحلة تُبنى وتُختبر وتُعرض عليك قبل التي تليها.
